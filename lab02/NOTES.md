различие git и githab : git - распределённая система контроля версий (VCS). Программа, которая работает локально на вашем компьютере.
github - веб-платформа для хранения Git-репозиториев и совместной работы. Надстройка над git.

«Использованные команды»: git status - показывает общую картину: что изменено, что добавлено в индекс (staging area), что не отслеживается.
git diff - показывает построчные различия между рабочей директорией и индексом (staging area). То есть — что вы изменили, но ещё не добавили через git add.
git diff --staged - показывает различия между индексом и последним коммитом. То есть — что уже добавлено через git add и попадёт в следующий коммит.

Ветка (branch) - это подвижный указатель на коммит. Не копия файлов, не отдельная папка — просто ссылка с именем.
Когда вы делаете коммит, Git:создаёт новый коммит с текущим коммитом , передвигает указатель текущей ветки на этот новый коммит , HEAD остаётся на той же ветке.
Слияние - это объединение историй двух веток. Git пытается свести изменения так, чтобы в результате получился один коммит, содержащий работу обеих веток.
